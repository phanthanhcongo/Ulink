## 📌 HƯỚNG DẪN ĐIỀN DỮ LIỆU

1. **Vui lòng không thay đổi tên các cột tiêu đề** để hệ thống có thể import dữ liệu tự động.
2. **Các cột bắt buộc (*)**: *Danh mục Cha, Danh mục Con, Tên sản phẩm, Mã SKU, Đơn vị tính, MOQ, Giá sỉ cơ bản*.
3. **Đơn vị tính**: Điền chính xác các đơn vị tiêu chuẩn (*Đôi, Cuộn, Hộp, Bộ, Thùng, Kg, Tấm, Gói, Can, Chai, Cái*).
4. **Thuộc tính biến thể**: Điền theo định dạng `Tên thuộc tính: Giá trị 1, Giá trị 2` (Ví dụ: `Kích cỡ: S, M, L, XL | Màu sắc: Xanh, Trắng`).
5. **Thông số kỹ thuật**: Điền dạng `Tên thông số: Giá trị` (Ví dụ: `Cấp sạch: ISO Class 5 | Điện trở: 10^6 - 10^9 Ω`).
